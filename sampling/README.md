
정상 거래를 그래프에서 빼는 다운샘플링은 하지 말고, 손실(loss)에 참여하는 정상 target 간선만 줄이는 다운 샘플링을 해야 한다.

그리고 실험은 어떤 샘플링을 고르냐 보다 샘플링 비율(r)과 양성 손실 비중(π_eff)을 분리해서 돌려야 의미 있는 결과가 나온다.

두 개의 다른 양

r = 샘플링 비율 — 학습 데이터에 정상 거래가 양성 1건당 몇 건 들어 있냐. 데이터 양·학습 시간·추정 분산을 정하는 숫자.

π_eff = 양성 손실 비중 — 손실 함수 안에서 양성이 차지하는 가중치 합의 비율. 모델이 "양성을 얼마나 중요하게 보냐"를 정하는 숫자. 이게 결정 경계를 움직여.
