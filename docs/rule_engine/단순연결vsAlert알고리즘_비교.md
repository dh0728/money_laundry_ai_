# 이진분류 모델에서 계좌 단순 연결 vs Alert 알고리즘 비교 실험

## 실험 설정
- Alert 생성기 : 현재 서비스의 Alert 생성기
- 단순연결 : 씨앗끼리 계좌를 공유하면 같은 묶음, 금액·방향·바쁜 계좌는 보지 않는다. 시간 제한(7일, 4일, 1일)만 바꿔 본다
- Dataset : HI-Medium
- 평가에서 빼는 패턴 : STACK, BIPARTITE
- 모델 : 서비스 이진 모델 파일 사용
- 기간 : 09.01 ~ 09.16
  - 이력만 보는 구간 : 09.01 ~ 09.07 (7일. 피처에는 쓰고 점수·Alert는 안 냄)
  - 평가 구간 : 09.08 ~ 09.16 (9일. 점수 내고 씨앗·Alert 만들고 정답과 비교)
  - 안 쓰는 구간 : 09.17 ~ 09.28 (정상 거래가 끊겨서 제외)
- 임계값 : 0.194997844

- 씨앗 보강 하한 (ALERT_SEED_LOW) : 0.1
  - 1단계(이중 임계값)에서 쓰는 값
  - 점수가 임계값(0.195)에는 못 미치지만 0.1 이상이고, 기존 씨앗과 계좌를 공유하는 거래를 씨앗으로 올린다
- 연결 바닥 거래 (ALERT_CHAIN_FLOOR) : 0.01
  - 2단계(금액 비율 연결)에서 쓰는 값
  - 씨앗에서 출발해 받은 계좌의 이후 출금, 보낸 계좌의 이전 입금을 따라가며 씨앗으로 올린다
  - 조건: 7일 이내, 금액이 0.5~1.05배, 최대 6단계
  - 이때 점수가 0.01 이상이고 금액을 아는 거래만 따라간다 (점수가 사실상 0인 거래는 안 탄다)

- 16일 뒤로 이어지는 패턴은 구간(16일) 안에 끝나는 시도와 구간되로 이어지는 시도를 분리해서 확인함
  - 평가 대상은 6종 중 평가 구간 안에 거래가 2건 이상 있는 시도 1,291개

## 내 고찰

### 1. 단순연결을 빠짐없이 담는 성향이 있고, Alert는 정답 모양대로 끊는 성향이 있음
- 단순 연결은 세탁 거래를 거의 안 놓친다 (재현율 0.971, 시도를 온전히 한 묶음으로 만든 비율 90.9%)
- 대신 묶음이 지저분하다. 쌍 정밀도 0.338, 정상이 섞인 묶음이 44.2%, 여러 시도가 한 묶음이 된 경우가 13.0%
- Alert 알고리즘은 반대다. 재현율 0.924, 온전 비율 72.7%로 덜 담지만 쌍 정밀도 0.657, 전부 세탁인 Alert가 79.6%
- 묶음이 정답 시도와 완전히 같은 비율은 Alert 알고리즘 52.4%, 단순 연결 31.1%

### 2. 차이가 나는 이유
- 단순 연결은 계좌 하나만 겹쳐도 건너건너 이어진다. 그래서 계좌를 같이 쓰는 다른 시도와 정상 씨앗이 한 덩어리가 된다 (최대 225건, 시도 26개가 한 묶음)
- Alert 알고리즘은 계좌 공유만으로는 안 묶고 부채꼴·릴레이·금액 흐름 같은 구조 조건을 통과해야 묶는다
- 단순 연결이 6종 시도에 붙인 다른 거래 25,510쌍이 Alert 알고리즘에서는 37%만 같은 Alert에 남고, 43%는 다른 Alert로 분리, 20%는 탈락했다
- 정상 씨앗 제거율: 단순 연결 32%, Alert 알고리즘 71%. 탈락한 정상 1,293건 중 1,205건이 "구조 없음(NO_STRUCTURE)"

### 3. 시간 제한은 이 데이터에서 변수가 아니다
- 단순 연결에 7일 제한을 걸어도 무제한과 결과가 같고, 4일도 거의 같다 (온전 89.6%). 1일로 줄여야 무너진다 (38.9%)
- Alert 알고리즘에서 쪼개진 시도 149개 중 조각 사이가 96시간을 넘는 건 3개뿐이고, 145개는 조각끼리 계좌를 공유한다
- 즉 두 방법의 차이는 시간이 아니라 구조 조건에서 나온다

### 4. Alert 알고리즘의 비용
- 묶으면서 6종 세탁 558건이 어느 Alert에도 못 들어가고 빠진다 (구조 없음 248, 연결만 147, 크기 상한 129, 셀프이체 33, 기간 상한 1)
- GATHER-SCATTER에 약하다. 온전 비율 47.6% (단순 연결 86.1%), 쪼개진 시도의 36%가 이 패턴
- 2건짜리 시도에 약하다. 온전 비율 66.0% (단순 연결 94.8%)
- STACK·BIPARTITE는 구조로 인식하지 못한다 (묶은 뒤 재현율 0.75, 0.11). 이번 평가에서는 제외함

### 5. 해석할 때 주의할 점
- 채점 기준이 정답 "시도" 단위다. 여러 시도가 한 Alert에 든 97개 중 96개는 시도끼리 계좌를 직접 공유한다. 심사 관점에서는 한 사건으로 봐도 되는 경우라, 이 기준은 잘게 끊는 쪽(Alert 알고리즘)에 유리하다
- 합성 데이터(HI-Medium) 결과다. 이진 모델은 같은 생성기로 만든 HI-Large로 학습한 것으로 알고 있어 씨앗 품질이 실제보다 좋을 수 있다
- 임계값 0.195는 HI-Medium에 맞춰 고른 값이 아니고, 씨앗 보강 값(0.1 / 0.01)은 이전 모델 기준 임시값이다. 보강으로 들어온 876건 중 505건이 정상이었다
