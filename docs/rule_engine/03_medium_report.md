# 패턴 룰로 alert를 생성하는 방법 실험

## 패턴별 룰 결과와 이유 (HI-Medium, 평가 구간 09-08 ~ 09-16)

- 정밀도 = 고른 거래 중 세탁 비율, 재현율 = 그 패턴의 세탁 거래 중 고른 비율
- "(Small)" 은 HI-Small 원장(09-05 ~ 09-10)에서 확인한 근거
- 시도 크기 = 09-05 ~ 09-16 안에 있는 그 시도의 세탁 거래 수

### FAN-IN — 처참함

조건 : 첫거래 + 5천 USD 이상, 7일, 송금 계좌 2개 이상
고른 거래 : 28,446
정밀도 : 10.2%
재현율 : 69.2%

정상 계좌도 "새 상대 여럿에게서 받는" 모양이 흔하고, FAN-OUT 과 달리 금액 하한으로 정상을 못 걸러냄
- 같은 7일 · 2개 이상에서 필터만 바꾸면: 필터 없음 13,299,357건(0.06%) → 첫거래 455,594건(1.1%) → 첫거래 + 1천 256,813건(1.5%) → 첫거래 + 5천 28,446건(10.2%). 끝까지 올려도 10%
- 정상 계좌가 새 상대에게서 받는 돈은 수천 USD대(중앙값 2,460 USD)라 세탁 금액대(중앙값 6,954 USD)와 겹침. 1천 USD 로 걸러도 정상 2,059개, 5천 USD 로 걸러도 224개가 남음. 세탁은 40개 (Small)
- 조건값을 올려도 소용없음: 2개 이상 10.2% → 6개 이상 9.6% → 10개 이상 4.9% → 16개 이상 0.01%. 세탁은 송금 계좌가 최대 16개인데 정상 수취 계좌는 그보다 많이 받음
- 어떤 조건값이든 정밀도가 10% 근처라, F1 기준으로는 재현율이 제일 높은 2개 이상이 골라짐
- 룰 6종 오탐 26,794건 중 25,558건이 FAN-IN. 매일 2,400 ~ 3,300건
- 모델과 같이 고른 2,881건은 정밀도 97.5%. 근거 표시용으로는 쓸 수 있음

### FAN-OUT — 잘 됨

조건 : 첫거래 + 1천 USD 이상, 7일, 수취 계좌 6개 이상
고른 거래 : 2,449
정밀도 : 96.2%
재현율 : 70.8%

"새 상대" 와 "금액 하한" 을 같이 걸어야 정상이 빠짐. 하나만으로는 안 됨
- 같은 7일 · 6개 이상에서 필터만 바꾸면: 필터 없음 3,307,502건(정밀도 0.1%) → 1천 이상만 541,475건(0.6%) → 첫거래만 126,603건(2.0%) → 둘 다 2,449건(96.2%)
- 정상 계좌가 새 상대 여럿에게 보내는 건 거의 다 소액(중앙값 35 USD)이라, 1천 USD 하한 하나로 정상 11,248개가 25개로 줄고 세탁은 89개 중 67개가 남음 (Small)
- 놓친 29% 는 작은 시도와 구간 끝. 조건이 6개 이상이라 시도 크기 5건 이하는 재현율 1 ~ 27%, 6건 이상은 92%
- 날짜별 재현율은 09-08 83% → 09-16 45%

### GATHER-SCATTER — 정확하지만 절반만 잡음

조건 : 첫거래 + 5천 USD 이상, 7일, 송금 · 수취 계좌 각 2개 이상
고른 거래 : 1,402
정밀도 : 99.1%
재현율 : 49.2%

"새 상대에게서 큰돈을 받고 새 상대에게 큰돈을 보내는" 계좌가 정상에 거의 없어서 정확함. 대신 조건이 세서 세탁도 많이 빠짐
- 같은 7일 · 2개 이상에서 필터만 바꾸면 정밀도 / 재현율: 필터 없음 0.08% / 88.3% → 첫거래 19.2% / 69.7% → 첫거래 + 1천 29.8% / 65.3% → 첫거래 + 5천 99.1% / 49.2%
- 패턴이 기간보다 김. 시도 길이 중앙값 9.5일, 7일 안에 드는 시도는 34%. 기간별 재현율이 1일 5.8% → 3일 24.7% → 7일 49.2% 로 계속 오르는 중이라 7일도 모자람
- 시도 전체를 다 잡는 경우는 3.5%, 한 건 이상 잡은 시도는 44.3%. 큰 시도의 일부만 잡음 (크기 10건 이상 재현율 62.5%, 9건 이하 0 ~ 26%)
- 놓친 1,174건의 54% 는 FAN-IN · FAN-OUT 룰이 대신 잡음 (모으는 쪽 · 뿌리는 쪽이 FAN 모양). 6종 합집합 재현율 76.8%

### SCATTER-GATHER — 잘 됨

조건 : 1천 USD 이상, 7일, 경유 계좌 4개 이상
고른 거래 : 2,052
정밀도 : 90.5%
재현율 : 68.2%

"같은 출발 계좌에서 나가 경유 계좌 여럿을 거쳐 같은 도착 계좌로 모이는" 모양 자체가 정상에 드묾. 필터 없이도 정밀도 61%
- 경유 계좌 수가 핵심: 2개 이상 23.0% → 3개 이상 69.8% → 4개 이상 90.5% → 5개 이상 92.6%. 경유 2 ~ 3개짜리는 정상에도 있음
- 1천 USD 하한을 얹으면 61.0% → 90.5%. 첫거래 필터는 정밀도는 그대로(91.1%)인데 재현율만 68.2% → 50.0% 로 깎아서 안 골라짐
- 기간이 필요함: 3일이면 재현율 9.0%, 7일이면 68.2%
- 놓친 32% 는 작은 시도와 구간 끝. 경유 4개면 거래가 8건 필요해서 크기 9건 이하는 재현율 1 ~ 31%, 10건 이상은 83%
- 날짜별 재현율은 09-08 84% → 09-16 43%

### CYCLE — 정확하지만 절반만 잡음

조건 : 필터 없음, 7일, 순환 거래 3건 이상 (이어지는 금액 비 0.8 ~ 1.25)
고른 거래 : 949
정밀도 : 85.9%
재현율 : 46.0%

닫힌 순환은 잘 잡는데, 닫히기 전 순환과 2건짜리 왕복은 구조상 못 잡음. 시도 단위로 전부 아니면 전무
- 시도의 39.0% 는 전부 잡고 58.8% 는 하나도 못 잡음
- 순환은 마지막 거래가 들어와야 닫힘. 날짜별 재현율이 09-08 68% → 09-16 16% 로 6종 중 가장 크게 떨어짐
- 2건짜리 왕복을 넣으면 재현율은 55.6% 로 오르지만 7,009건을 고르고 정밀도가 17.8% 가 됨. 정상 왕복 거래가 많아서 "3건 이상" 이 필요함. 4건 이상이면 99.8% / 42.2%
- CYCLE 시도 54개를 나눠 보면: 3건 이상이고 닫힌 26개는 전부 잡음 / 2건짜리 왕복 14개 / 데이터 끝 뒤로 이어지는 11개 / 거래가 순서대로 안 이어지는 3개 (Small)
- 닫히기 전 앞부분은 RANDOM 룰이 잡음 (CYCLE 세탁의 51.5%). 6종 합집합 재현율 68.7%
- 첫거래 필터는 못 씀. 경로의 모든 거래가 필터를 통과해야 해서 재현율이 46.0% → 5.9%

### RANDOM — 정밀도가 낮음

조건 : 1천 USD 이상, 7일, 경로 거래 6건 이상 (이어지는 금액 비 0.8 ~ 1.25)
고른 거래 : 2,091
정밀도 : 59.6%
재현율 : 57.2%

"금액이 비슷하게 이어지는 경로" 는 정상 거래끼리도 우연히 만들어짐. 기간이 길수록 더 많이 생김
- 기간별 (6건 이상) 정밀도 / 재현율: 1일 92.1% / 3.0% → 3일 83.6% / 36.9% → 7일 59.6% / 57.2%. 기간을 늘리면 재현율은 오르고 정밀도가 무너짐
- 길이를 올려도 한계가 있음: 7일에서 4건 이상 5.9% → 6건 이상 59.6% → 8건 이상 72.1% → 10건 이상 76.2%
- F1 기준이라 재현율 쪽 조건이 골라진 것. 첫거래 + 5천 USD 이상, 3일, 2건 이상이면 98.8% / 41.3% (1,894건)
- 작은 시도는 못 잡음: 크기 5건 이하 재현율 0 ~ 12%, 6 ~ 9건 88%
- 오탐 845건. 매일 37 ~ 130건
