# 03_medium 데이터셋으로 패턴 룰로 했을 때




## 결과

### fan-in 에서 결과가 처참함

조건 : 첫거래 + 1천 이상, 7일, 2개 이상
고른거래 : 28,446
정밀도 : 10.2%
재현률 : 69.2%

데이터 구조상 정상거래도 "새 상대 여럿에게서 받은" 모양이 흔함 + 금액 하한으로 정상을 걸러내는 게 힘듬(fan-out과 다르게)
- Fan-out은 정상 계좌가 새 상대 여럿에게 보내는게 거의 다 소액이라, 1천 USD하한 하나로 정상 11,248개가 25개로 줄고, 세탁은 89개 중 67개가 남음
- Fan-in : 정상 계좌가 새 상대에게서 받는 돈이 수천 USD대라 세탁 금액대와 겹쳐. 1천 USD로 걸러도 2,059개, 5천 USD로 걸로도 224개 남음
