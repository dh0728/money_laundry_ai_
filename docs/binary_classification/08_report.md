### 표기
- L(x) = ln(1 + x), G(Δ) = ln(2 + Δ분)
- 계좌 피처는 송신 계좌(`src_`) 와 수신 계좌(`dst_`) 에 각각 붙어 2열이 된다

## 평가 지표

| 지표 | 뜻 |
|---|---|
| `val_AP`, `test_AP` | 검증 표본(가중) · 테스트 전체의 AP. 양성 = 패턴 + 무패턴 |
| `AP_패턴` | 무패턴 양성을 빼고 정상 vs 패턴만으로 계산한 AP |
| `AP_무패턴` | 패턴 양성을 빼고 정상 vs 무패턴만으로 계산한 AP |
| `@0.1%`, `@1%` | 테스트 전체에서 점수 상위 0.1% (26,809건) · 1% (268,083건) 를 알림으로 올린 컷. 조건마다 알림 수가 같다 |
| `패턴R` | 패턴 양성 중 알림에 든 비율 |

## 읽히는 것
1. **패턴 탐지는 공통 17종만으로 거의 다 된다.** `base` 가 상위 0.1% 컷에서 패턴 recall 0.962, precision 0.759. B · G 를 빼면 어떤 묶음을 얹어도 이 두 값은 ±0.006 안에서만 움직인다
2. **상위 0.1% 알림에서는 뭘 얹어도 구성이 거의 같다.** 무패턴 양성은 B(896건) 를 빼면 1,090 ~ 1,230건(14,273건 중 8% 안팎) 에서 안 움직인다
3. **C(소유주) 와 E(당일 흐름 · 금액 대비) 는 느슨한 컷에서 무패턴을 더 잡는다.** 무패턴 recall@1% 가 `base` 0.550 → C 0.657, E 0.615. test AP 도 +0.021, +0.015. 검증과 테스트에서 오른 폭이 비슷하다. 다만 그 컷의 패턴 precision 은 0.078 수준이다
4. **E 는 네 판정 지표가 모두 오른 유일한 묶음이다.** KYC 를 쓰지 않는다
5. **F(반복 금액) 는 효과가 없다.** `pair_amount_seen_before_day` 가 중요도 1위(20%) 인데도 test AP −0.003, 비ACH 정상 오탐은 거의 두 배. 07 의 `amtseen` 결과와 같은 방향이다
6. **A(내 실험의 단기 상대 수) 는 더해 주는 것이 없다.** test AP +0.002. 판정은 ↑ 지만 시드 표준편차가 작아서 붙은 것이고 크기는 의미 없다
7. **B(시간대) 는 해롭다.** 검증 AP 는 그대로(0.669) 인데 테스트만 0.656 → 0.612, 패턴 precision 0.759 → 0.713, 비ACH 정상 오탐 1,472 → 5,313건. "검증은 멀쩡, 테스트만 하락, 비ACH 오탐 증가" 는 07 의 `no_pf` 와 같은 모양이다. 반대로 `base` 는 결제방식도 시간도 없는데 무너지지 않았다 → 07 에서 결제방식을 뺐을 때 테스트가 무너진 것은 시간 피처(`timestamp`) 가 같이 있었기 때문일 가능성이 크다 (미확인)
8. **G 는 엇갈린다.** 무패턴 recall@1% 는 오르지만 패턴 precision 이 0.759 → 0.739 로 내려가고, 검증 AP +0.021 에 비해 테스트는 +0.002 다. 성격이 다른 피처 13열을 한 묶음에 넣은 탓일 수 있다
9. **결제방식이 없어도 오탐의 대부분은 ACH 정상 거래다.** `base` 의 정상 오탐 6,163건 중 4,691건이 ACH. 비ACH 양성(3,886건) 은 어느 조건에서도 36 ~ 53건만 잡힌다
