AML 알림 트리아지도 룰엔진 알림으로 2단계 모델을 학습한다(Jullum et al., JMLC 2020).


#### 이진분류에서 오탐한걸로 유형분류에 클래스를 추가하는 방식에 근거가 되는 레퍼런스(아직 못읽어봄 이건ㅠㅠ)
1. Viola–Jones 캐스케이드 (2001) — 가장 고전적인 근거
얼굴 검출기를 여러 단계로 쌓는데, 각 단계는 앞 단계를 통과한 오탐(false positive)으로만 학습해. 앞 단계가 거른 쉬운 정상은 다음 단계가 볼 일이 없으니 학습에도 안 넣는다는 논리가 네 설계 그대로야.
→ Viola & Jones, “Rapid Object Detection using a Boosted Cascade of Simple Features”, CVPR 2001.

2. Faster R-CNN (2015) — "정상 클래스 포함"의 근거
1단계(RPN)가 후보 영역을 올리고, 2단계 분류기가 그 후보를 K개 클래스 + background 클래스로 분류해. 2단계는 정답 객체가 아니라 RPN이 올린 후보로 학습하고, 후보 중 정답과 안 겹치는 것들이 background 라벨을 받아. 이게 "정상 = 이진 모델이 올렸지만 라벨 0인 거래"와 정확히 같은 구조고, background 클래스 없이 K개로만 학습하면 오탐이 아무 클래스에나 찍히는 문제도 같아.
→ Ren, He, Girshick, Sun, “Faster R-CNN”, NeurIPS 2015.

3. Cascade R-CNN (2018) — "학습 분포 = 추론 분포" 근거
뒷단계를 앞단계 출력 분포로 학습하지 않으면 train/inference 분포 불일치(mismatch) 가 생겨 성능이 떨어진다는 걸 실험으로 보임. 단계별로 앞 단계 출력을 그대로 다음 단계 학습 데이터로 쓰는 게 해법.
→ Cai & Vasconcelos, “Cascade R-CNN: Delving into High Quality Object Detection”, CVPR 2018.

4. Hard negative mining / OHEM — "전체 정상이 아니라 헷갈린 정상만"의 근거
모델이 틀린 정상(hard negative)만 모아 다시 학습하는 기법. 쉬운 정상은 학습 신호가 거의 없어서 넣어봤자 비용만 든다는 게 요지.
→ Shrivastava, Gupta, Girshick, “Training Region-based Object Detectors with Online Hard Example Mining”, CVPR 2016.

5. Open-set recognition — "정상 클래스가 없으면 생기는 문제"의 근거
학습 때 못 본 클래스가 추론에 들어오면 폐쇄형 분류기는 반드시 아는 클래스 중 하나로 찍고, 보통 높은 확신으로 틀린다는 걸 체계적으로 보인 연구들.
→ Scheirer et al., “Toward Open Set Recognition”, TPAMI 2013 / Bendale & Boult, “Towards Open Set Deep Networks (OpenMax)”, CVPR 2016.

6. AML 쪽 사례
은행 실무의 AML 알림 트리아지가 같은 구조야. 1단계 룰엔진이 알림을 올리고, 2단계 ML 모델은 룰엔진이 올린 알림(대부분 오탐) 으로 학습해서 진짜/오탐을 가르는 식. 노르웨이 DNB 은행 사례:
→ Jullum, Løland, Huseby, Ånonsen, Lorentzen, “Detecting money laundering transactions with machine learning”, Journal of Money Laundering Control, 2020.
