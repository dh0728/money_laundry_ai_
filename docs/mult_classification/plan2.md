## Q. 패턴 데이터만으로 학습시키는 게 괜찮은가?

정답 패턴 서브그래프만으로 학습하면
- 깨끗하고 학습이 쉽다
- 하지만 서비스 입력(alert)과 모양이 다르다. alert를 입력으로 줘도 alert는 정답 패턴 서브그래프가 아니다
  - 씨앗: 이진 모델이 올린 거래라서 일부 누락·오탐이 있음
  - 경계: 전후 2일·2단계·100건 한도라서 정상 거래가 섞임
  - 시간: cutoff까지의 조각만 보임 (패턴은 최대 70여 일)
  - 오탐 alert: 세탁이 없는 alert도 들어옴 → 정상 클래스가 없으면 패턴 중 하나로 억지 분류

### 대안
| 학습 입력 | 서비스와의 차이 | 용도 |
|---|---|---|
| 정답 패턴 서브그래프 | 경계·조각·이진 오류 모두 다름 | 상한 측정 |
| 정답 씨앗으로 만든 alert | 이진 오류만 다름 | 기본 학습 |
| 이진 모델이 실제로 올린 alert (검증 기간) | 같음 | 최종 학습·평가 |

### 확인 방법
정답 씨앗으로 alert를 만들고 패턴 인스턴스 대비 커버율·순도를 측정한다.
둘 다 1에 가까우면 정답 패턴만으로 학습해도 된다.


## Q. 이진, 유형 둘로 나누는게 의미가 있으려면?

### 1. 1단계 이진 분류 점수를 입력으로 쓸 때
- 유형 모델이 "이웃 거래들의 이진 점수"를 엣지 피처로 받는 경우 어느 이웃이 같이 의심스러운지가 패턴 모양의 가장 강한 단서인데, 이건 1단계를 거쳐야만 생기는 정보임. 앞에서 말한 "의심 거래만 모은 그래프"의 장점을 정상 거래를 지우지 않고 살리는 방법이기도 하다.
주의할 점이 하나 있음. 학습 기간의 이진 점수는 과적합돼 있어서, 검증 기간 점수나 시간 기준 OOF 점수를 써야 해.
  - 검증 기간 점수 쓰기
    - 이진 모델은 검증 기간 라벨로 학습하지 않았으니 그 기간 점수는 정직하다. 유형 모델을 검증 기간으로 학습하고 테스트 기간으로 평가하면 되는데 간단하지만 학습 데이터가 2주 정도로 줄어드는 단점이 있다.
  - 시간 기준 OOF(out-of-fold) 점수 만들기
    - 학습 기간을 주 단위로 나누고, 매번 앞선 기간으로만 학습한 이진 모델로 다음 주에 점수를 매기는 방식이다. 예를 들어 1~4주로 학습해서 5주를 채점하고, 1~5주로 학습해서 6주를 채점하는 식으로 반복한다. 그러면 학습 기간 대부분에 정직한 점수가 생겨. 대신 이진 모델을 여러 번 학습해야 해서 HI-Large GNN 기준으로는 비용이 커.

#### 학습 기간의 이진 점수가 과적합이 무슨 소리냐
이진 모델은 학습 기간 거래의 라벨을 보면서 학습했어. 그래서 같은 거래에 점수를 다시 매기면 세탁은 0.98, 정상은 0.01처럼 정답에 거의 붙은 점수가 나와. 일종의 외운 답임
유형 모델을 이 점수로 학습시키면 "이웃 점수가 0.9 이상이면 같은 패턴 구성원"이라고 배워서. 사실상 이웃의 정답 라벨을 피처로 받은 것과 같아서, 라벨 누수가 생긴다
그런데 서비스에서는 이진 모델이 처음 보는 거래에 점수를 매겨서. 같은 fan-in인데도 이웃 점수가 0.55, 0.3처럼 애매하게 섞여서 나옴. 유형 모델은 그런 점수를 본 적이 없으니 "이웃이 별로 의심스럽지 않다 → 패턴이 아니다"로 잘못 판단하게됨


### 2. 더 넓고 긴 이웃을 볼 때
- 이진 모델은 모든 TARGET 거래에 돌아야 하니 이웃을 좁게 잡을 수밖에 없어. 반면 유형 모델은 걸러진 소수 거래에만 돌기 때문에 더 많은 hop이나 더 긴 시간 창을 감당할 수 있음. 패턴이 한 달 넘게 걸친다는 점을 생각하면 이건 실질적인 이득이 될지도?

### 3. 학습 분포를 다르게 가져갈 때
이진은 전체 거래에 가중 손실을 쓰고, 유형은 세탁 거래와 고득점 정상 거래(hard negative)에 집중해서 학습하는 식으로 나누는 것

## Q. 패턴이 마지막 거래로 결정되는 경우 (예: cycle)

### 문제
- 패턴 라벨이 인스턴스 전체(미래 포함)에 붙어 있다 → cycle의 앞 거래도 cycle 라벨
- 그 날짜에는 닫는 거래가 없어서 관측 모양은 경로일 뿐이다
- 모델이 cycle이라고 답하는 이유는 둘 중 하나
  1. 이웃에 미래 거래가 들어감 (누수) → cutoff 마스킹 확인
  2. "이런 경로는 나중에 cycle이 된다"는 예측을 학습함 → 관측 설명이 아니라 미래 예측
